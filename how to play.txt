### TripPilot — India Edition
### Setup & Execution Guide

Both the **React frontend** and **Express backend** are completely configured and ready to run.

---

### Step 1: Start the Backend (Express API)

Open your first terminal (PowerShell or Command Prompt):

```powershell
cd server
npm run dev
```

* Backend server will start on: **`http://localhost:5001`**
* Health check endpoint: `http://localhost:5001/api/health`
* **MongoDB Note**: MongoDB is *optional* for generating itineraries! The app has a built-in offline engine with realistic Indian destinations (Jaipur, Varanasi, Kerala, Udaipur, Ladakh, Hampi). MongoDB is only needed if you want to permanently persist user accounts and saved trips.

---

### Step 2: Start the Frontend (Vite + React)

Open a second terminal window:

```powershell
cd client
npm run dev
```

* Frontend will start on: **`http://localhost:3000`**
* Vite automatically proxies all `/api` requests to `http://localhost:5001`.

---

### Step 3: Open in Your Browser

Navigate to:
👉 **`http://localhost:3000`**

---

### Key Features You Can Try Right Away:

1. **Layla.ai Style Conversational Prompt Bar**:
   - Type queries like: *"4 days in Jaipur with hill forts, stepwells and street food"* or click the suggestion chips.
2. **Interactive AI Re-Pacing Simulator**:
   - Tap *"🍽️ Add Street Food Trail"* or *"☀️ Avoid Midday 40°C Heat"* to preview real-time AI adjustments.
3. **1-Click Google Maps Navigation**:
   - Open any day's itinerary and click **`Open Route in Google Maps ↗`** to launch multi-stop GPS directions on your phone or desktop.
4. **Indian Transit Intelligence Ledger**:
   - See realistic auto-rickshaw (₹) and cab (₹) fare estimates and road mileage for each day.
5. **Add / Reorder / Delete Waypoints**:
   - Click `+ ADD STOP` to add curated local eateries (e.g. *Rawat Kachori*, *Blue Lassi*) or reorder stops with `▲` and `▼`.
6. **Dark & Light Mode Toggle**:
   - Click the Sun ☀️ / Moon 🌙 button in the top navigation bar to switch between dark cinematic mode and warm ivory light mode.
7. **Export to Apple/Google Calendar & WhatsApp**:
   - Download `.ics` files for mobile calendars or share full trip summaries to WhatsApp groups with 1 click.
